Abstract

I build the pipeline between a research idea and a system that stays up: retrieval-augmented generation, LLM agents, and the APIs and databases that carry them into production. Recently graduated and shipping since — five projects, two recognitions, one running theme: the backend matters as much as the model.

01Background

I graduated with a B.Tech in Computer Science and Engineering (AI & ML) from Keshav Memorial Institute of Technology, Hyderabad, in 2026. Most of what I know, I learned by shipping — an OCR-driven medicine assistant, a RAG-based quiz engine, a real-time fact-checking agent, and a civic platform that's now used to route real complaints.

The layer most AI demos skip is the backend that keeps a model useful.

My focus now is system design, distributed systems, and computer networks, alongside the AI/ML work itself. I'm looking for entry-level AI/ML or backend engineering roles where I can build production-grade systems, not just notebooks.

Case 02

Honest Deck

Ongoing
  • Real-time fact-checking API built on a LangChain ReAct agent (Groq Llama 3.3 70B) with five autonomous tools — web search, article scraping, domain-credibility scoring, prior-verdict lookup, and verdict finalization.

Keywords: FastAPI, LangChain, Qdrant, MongoDB, RAG
